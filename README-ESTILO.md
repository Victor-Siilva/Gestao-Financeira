# Gestão de Finanças — tema escuro

Esta versão mantém a estrutura e as funcionalidades do projeto original e altera apenas a camada visual (`src/styles.css`) para aproximar a interface da referência enviada: fundo preto/grafite, painéis escuros, bordas discretas e azul elétrico nos elementos ativos.

A aplicação continua sendo executada com `npm install` e `npm run dev`.
